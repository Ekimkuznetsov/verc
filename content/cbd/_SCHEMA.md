# Схема джерела бази знань CBD

Кожне джерело — окремий `.md` файл у цій теці. Ім'я файлу стає slug-ом сторінки
(наприклад `zakon-3528-ix.md` → `/resources/zakon-3528-ix.html`).

Файли, що починаються з `_` (як `_SCHEMA.md`, `_TEMPLATE.md`), **ігноруються**
збіркою — це службові файли.

## Поля frontmatter (YAML між `---`)

| Поле         | Обов'язкове | Опис |
|--------------|:-----------:|------|
| `title`      | так         | Повна назва джерела |
| `type`       | так         | Категорія: `law` \| `research` \| `application` \| `faq` |
| `summary`    | так         | 1–2 речення для картки в каталозі |
| `authors`    | ні          | Список авторів / орган, що видав |
| `year`       | ні          | Рік публікації (число) |
| `lang`       | ні          | Мова джерела (`uk`, `en`, ...); типово `uk` |
| `source_url` | ні          | Посилання на першоджерело |
| `tags`       | ні          | Список тегів для фільтрації/пошуку |
| `status`     | ні          | `published` (типово) \| `draft` — draft у продакшн не потрапляє |

## Тіло файлу

Звичайний markdown (заголовки `##`, списки, цитати). Використовуйте заголовки —
за ними RAG ріже текст на змістовні чанки для векторного пошуку.

Категорії (`type`):
- **law** — законодавство, постанови, накази, реєстри
- **research** — наукові дослідження, огляди, клінічні дані
- **application** — практичне застосування (реабілітація, hempcrete, агротехніка)
- **faq** — часті питання по проекту та CBD
